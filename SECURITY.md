# Security policy

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Use GitHub's
[private vulnerability reporting](https://github.com/serhatandic/yawm/security/advisories/new)
so the report, reproduction steps, and any proposed fix remain private.

Include the affected version and platform, the impact, and the smallest
reproduction you can provide. Repository contents may be sensitive, so remove
tokens, private source code, and identifying paths from screenshots or logs.

You should receive an acknowledgement within seven days. Confirmed issues will
be coordinated privately until a fix and release are available.

## Supported versions

yawm is currently pre-1.0. Security fixes are made on `main` and released in
the newest available build; older builds are not maintained separately.
